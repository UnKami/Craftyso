# 02 — Storefront (Consumer-facing)

Every page below is specified as: **purpose → content blocks → interactions →
AI/automation → edge cases.** Hebrew/RTL is the default rendering for all.

---

## 2.1 Home `/`

**Purpose:** get the visitor into a product or a search in one action. Not a
brochure.

**Blocks (in order, mobile):**
1. **Search-first hero** — oversized search field with rotating placeholder
   ("חפש כפתור, סרט, אבזם…"), camera button, and 6 colour swatches. No
   full-bleed carousel above it.
2. **Shop by look** — 8–12 visual category tiles using real product macro
   photography, not icons.
3. **Personalised rail** — "המשך מאיפה שהפסקת" / recently viewed / reorder
   consumables (thread, elastic) for returning customers.
4. **Seasonal module** — auto-swapped by the merchandising automation: Purim
   costume trims, summer hats, bridal, back-to-school, Rosh Hashana.
5. **New arrivals** — populated automatically when a shipment is received.
6. **Project of the week** — a project page with a one-click "add all materials".
7. **In the shop today** — live "available now at Levontin 9" strip if the
   visitor is in Tel Aviv (geo, permissioned) or has chosen pickup before.
8. **Trade / import strip** — two clear doors: "קונים לעסק?" and "צריכים לייבא?"
9. **Trust row** — shipping times, returns, the physical shop, secure payment,
   accessibility.

**AI/automation:** rails 3, 4, 5, 6 are all generated by the merchandising
agent (doc 10 §4.3); the hero placeholder rotates with trending queries.

**Edge cases:** first-time visitor gets category tiles instead of the
personalised rail; no geo permission → no "in the shop" strip, never a prompt
wall.

## 2.2 Category `/c/[...path]`

**Purpose:** narrow a physical need fast.

**Blocks:**
- Breadcrumb + category header with a one-line human explanation ("סרטי סטן —
  רוחב 3–100 מ״מ, 40 גוונים, למכפלות, נעליים ואריזה").
- **Subcategory chips** (horizontally scrollable) before the grid.
- **Filter bar, sticky:** colour swatches (not names), width slider (mm),
  material, pack size, price, availability (`במלאי` / `בחנות בת״א` / `בדרך —
  מגיע בתאריך`), and "ניתן לייבוא בהזמנה".
- Product grid: image, name, price, price-per-unit (per metre / per 100),
  colour dots for other variants, stock hint, quick-add with quantity stepper.
- **Compare tray** (up to 4) for near-identical trims.
- Category-level guide block at the bottom (SEO + genuinely useful): how to
  choose a width, how to measure, care.

**Interactions:**
- Filters update the URL (shareable), never a full page reload; results stream.
- Quick-add opens an inline variant/quantity popover — never navigates away.
- Infinite scroll with a real "load more" fallback + preserved scroll position
  on back (critical, and where most stores fail).

**AI/automation:** facet values are generated by catalog enrichment; ordering
is by a learned relevance blend (conversion × margin × stock health), with
manual pinning available in `/admin/collections`.

## 2.3 Product `/p/[slug]`

**Purpose:** answer "is this the right physical thing, and can I get it when I
need it?"

**Blocks:**
1. **Gallery** — macro shots, a scale reference (coin/ruler overlay), true-colour
   swatch photo, on-material lifestyle shot, optional 15s video.
2. **Identity** — name, SKU, short spec line (material · width · finish).
3. **Variant selector** — colour as swatches with names on hover/long-press;
   size/width as a segmented control; never a bare dropdown of hex codes.
4. **Price block** — unit price, price per metre/unit, quantity breaks shown
   inline ("10+ ₪3.20 · 50+ ₪2.75"), trade price if logged in as trade.
5. **Quantity** — stepper + presets (1 / 5 / 10 / מטר / גליל שלם) + a
   **calculator** ("כמה צריך לשמלה?").
6. **Availability, honestly:**
   - `במלאי — נשלח היום` with count when low,
   - `זמין בחנות בתל אביב` (live),
   - `אזל — מגיע ב־12.10` from the open PO/shipment ETA,
   - `ניתן להזמין ביבוא — מ־500 יח׳` → import request flow.
7. **Delivery estimate** — computed for the visitor's area, with a date not a
   range where possible; pickup option with today's shop hours.
8. **Sticky add-to-cart bar** on mobile (price + qty + button) — always visible.
9. **Match & pair** — "מה מתאים לזה": AI pairings (thread that matches this
   ribbon's colour, buckle that fits this strap width), and "found in these
   projects".
10. **Full specs table** — every physical attribute, in a scannable table.
11. **Reviews & photos** — with the "what did you make?" prompt.
12. **Q&A** — customer questions, AI-drafted answers approved by staff.
13. **Bulk / trade CTA** — "צריך כמות גדולה? קבל הצעת מחיר" → quote flow.

**AI/automation:** description, specs, alt text, SEO metadata and pairings are
generated at listing time (doc 10 §4.1) and re-checked when the supplier data
changes. Q&A drafts and review summaries are generated; both need approval.

**Edge cases:** out-of-stock never becomes a dead end — it always offers
back-in-stock alerts, the nearest colour match, pickup elsewhere, or import.

## 2.4 Visual & colour finding

### `/search/visual` — "צלם ומצא"
Camera / gallery / paste. Upload → we detect objects in the photo, let the user
tap the item they mean (buckle in a bag photo), then return visually similar
catalog items ranked by similarity, with a confidence-honest header ("דומים
למה שצילמת"). Always shows "לא מצאתם? נייבא עבורכם" as the last card.

### `/match` — "התאם לחומר שלי"
Photograph the fabric/leather. We extract dominant colours, texture and scale,
then return: matching threads, ribbons, buttons, zips, and a printable swatch
sheet. Optionally posts to a staff member for a human second opinion.

### `/color` and `/color/[hex]`
A wall of colour. Pick a swatch → everything we stock near it across all
categories, sorted by ΔE. Useful in-store, useful for stylists, and a strong
SEO surface ("סרט סטן זהב", "כפתור שחור מט").

## 2.5 Projects & bundles

`/projects/[slug]` — a project (a tote bag, a Purim costume, a bridal veil)
with photos, steps, difficulty, and a **complete materials list** where every
line is a real SKU with quantity. One button: "הוסף את כל החומרים לסל" with
per-line opt-out and automatic quantity scaling ("×2 שמלות").

`/bundles/[slug]` — packaged kits, priced with a bundle discount. Bundles can
be human-curated or AI-composed from co-purchase data; both go through
approval.

**Why it matters:** it converts a materials problem into one transaction, and
it is the single best differentiator against a generic marketplace listing.

## 2.6 Cart `/cart`

- Line items with thumbnail, variant, unit price, per-unit price, quantity
  stepper, and **stock revalidation on load** (never surprise at checkout).
- **Shipping progress** to free threshold + "add ₪18 for free delivery"
  suggestion pulled from complementary items.
- Pickup toggle: switching to "איסוף בחנות" re-checks per-line shop stock and
  flags what would need to be ordered.
- Split awareness: if part ships now and part in 3 weeks, say so and let the
  customer choose split shipment or wait.
- Save cart / share cart link (WhatsApp) — trade customers do this constantly.
- Coupon field, gift note, and a "צריך את זה עד תאריך" date input that drives
  the fulfilment queue's priority.

## 2.7 Checkout `/checkout`

**One page, four blocks, no account required.**

1. **Contact** — phone-first (Israeli habit), email optional but requested for
   the invoice; OTP login offered inline for returning customers.
2. **Delivery** — pickup at Levontin 9 (with today's slot), courier to address,
   locker, or Israel Post. Address with autocomplete over the Israeli
   street/city dataset + house/apartment/floor/entrance fields. Live rate and
   date per option.
3. **Payment** — credit card via Grow, **Bit**, Apple Pay / Google Pay, and
   for approved trade accounts "לחיוב על החשבון" (on account, per terms).
4. **Review & pay** — totals with VAT stated, sticky pay button.

Rules:
- No step navigation; everything visible, sections collapse as completed.
- Errors inline, in Hebrew, specific ("מספר הבית חסר").
- Payment failure never loses the cart or the entered data.
- Invoice/receipt (חשבונית מס / קבלה) issued automatically on capture (doc 12).
- Abandonment captured at every field for the recovery automation, with clear
  consent.

`/checkout/success/[orderId]` — order number, what happens next with dates, a
tracking link, "add to calendar" for pickup, WhatsApp opt-in for updates, and
a first-order coupon for the next visit.

## 2.8 Order tracking `/order/track/[token]`

Tokenised, no login. Shows the order timeline (received → paid → picked →
shipped → out for delivery → delivered), carrier tracking inline, the invoice
PDF, "something's wrong" button that opens a support thread, and — for items
that came from an inbound shipment — the honest "מגיע לארץ ב־…" milestone.

---

## 2.9 Support & information pages

- `/contact` — WhatsApp (primary), phone (03-5106888, click to call), the shop
  address + map + hours, and a form that creates a real support thread with an
  AI first response and a promised human time.
- `/faq` — searchable, grouped, each answer linked to the object it concerns
  (shipping page, returns policy).
- `/shipping`, `/returns`, `/terms`, `/privacy` — editable in `/admin/content`,
  versioned.
- `/accessibility` — IS 5568 statement, contact for accessibility issues, and
  in-page controls (contrast, text size, reduced motion, link highlighting)
  persisted per visitor.
- `/store` — the shop as a first-class page: photos, hours (with holiday
  overrides), parking, live "in stock here" search, and appointment booking
  for bulk buyers.

## 2.10 Cross-cutting storefront features

| Feature | Notes |
|---------|-------|
| **Guest everything** | Browse, cart, checkout, track, return — all without an account. Accounts add convenience, never gate. |
| **Back-in-stock & price-drop alerts** | On product & variant level, via WhatsApp/email/SMS; fired automatically on receipt or price change. |
| **Recently viewed / continue** | Cross-device once logged in. |
| **Wishlists / shopping lists** | Shareable links; a designer sends a list to a client. |
| **Reviews with photos** | Requested automatically post-delivery; AI-summarised on the product page. |
| **Live chat / WhatsApp** | Same thread across channels; AI first, human always available (doc 10 §4.2). |
| **Gift cards** | Digital, redeemable in shop and online. |
| **Loyalty** | Points on spend, bonus for reviews/UGC, tier perks; visible in cart. |
| **Referrals** | Give ₪X / get ₪X, tracked to order. |
| **PWA** | Installable, offline catalog cache, push notifications for alerts. |
| **Performance budget** | LCP < 2.0s on 4G, JS < 120KB on category pages, images AVIF/WebP via CDN. |
| **SEO** | Product/Offer/Review/BreadcrumbList/FAQ JSON-LD, auto sitemap, Hebrew-aware metadata generation, and 301s from every legacy URL. |
